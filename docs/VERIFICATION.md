## 已通过

- 后端 32 项自动测试通过，覆盖包状态、APT 计划变更、命令参数、权限取消、卸载后状态检查、Flatpak scope、手动安装边界、包装脚本、共享图标/配置保留以及未知值排序。
- 手动卸载的真实删除仅作用于测试创建的临时目录；配置保留、目标文件替换和目录符号链接边界通过。
- 实际应用烟测验证名称搜索、来源筛选、空结果、日期双向排序。
- 四个列标题逐个验证双向切换、下拉选项同步及箭头方向；实际展开 GTK 排序菜单并检查截图，普通项和选中项均清晰。标题的文本布局宽高未超过分配空间。
- APT 卸载模拟、确认窗口取消通过；用户目录独立安装生成明确文件清单。涉及系统组件的计划必须输入应用名称才可确认。

- 用户级安装的菜单名称、图标、安装副本一致性、从安装目录运行以及单实例通过。
- Debian 包构建与 desktop-file-validate 通过，APT 模拟安装无删除。

本机原始运行报告留在本地，不提交公开仓库。可复现的示例界面检查使用 `scripts/preview.py`；公开截图仅含示例数据：[主界面](screenshots/main.png)、[排序菜单](screenshots/sort-menu.png)。GitHub Actions 从 1.1.4 起在 Ubuntu 24.04 / 26.04 的 AMD64、ARM64 上运行自动测试、示例 GTK 检查和实际包安装/移除；先统一打包，再把同一份包分发至四个运行器。结果以对应提交的实际运行状态为准。

## 1.1.4 ARM64 与通用安装包

四平台门禁包含：

- uname、dpkg 架构、Ubuntu VERSION_ID 与预期平台一致；ARM64 为 aarch64 / arm64。
- 系统 Python 和 PyGObject 扩展为目标架构 ELF（ARM64 183，AMD64 62），确保执行了目标运行环境。
- 安装包 Architecture=all，版本正确，不含架构专用 ELF 或 Python 字节码；四个作业下载同一个构建制品并核验同一个 SHA256。
- 32 项后端测试，包括双架构包名/安装日志处理；原生 Xvfb 中检查排序、菜单、自身图标和模拟卸载后退出。
- 实际安装后读取安装目录中的程序，检查来源/版本/图标与自卸载计划；通过真实 APT 移除本工具，再检查核心依赖仍已安装。

本机 AMD64 的 32 项测试和包结构/运行架构检查已通过。ARM64 与其他 CI 平台的完成状态、原生环境和同包摘要证据保存为各作业的 platform-report.json、ci-installed-report.json，随对应提交的 Actions 制品提供；未完成的作业不能记为通过。
